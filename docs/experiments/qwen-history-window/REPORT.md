旧协议→历史图同时改变历史覆盖背景、面积扣除基线、提示词与总覆盖统计，属于整体输入方案对照，不能拆成单一因果因素。无历史片段主要控制prompt/额外统计/图例影响，不能算历史能力验证。

隐藏黄线→完整历史图仅增加黄色历史路径，prompt、深浅蓝覆盖、统计、当前红线、起终点、视野与比例相同。这个配对可隔离黄线对输出的影响，但没有人工真值仍无法判定变化是否正确。

整体评分变化也可能来自面积数值或prompt，不证明模型理解历史重复搜索。无前置历史的256步对照也出现输出变化，进一步说明不能把协议变化直接当历史推理能力。隐藏黄线图仍保留历史覆盖底色，并不是完全没有历史信息。
