# Qwen四组推理恢复：实现与预先固定设置

基于本机共享Git仓库的1e7df23建立phase2/qwen-memory-four-arm独立工作树；旧运行f0e093c及完整结果保留。本轮实现、工程测试与发布，四组正式4200作业仅准备命令，未经用户下一步指令不提交，不启停原训练。必要GPU烟测使用独立短PBS测试，不能当正式性能实验。

共同底座为coverage256125,952,000步（ckpt.245，SHA988c9ecc5b0c704e9a4780f636739aec17cbd323d613f0fbdde4699296886c2c），只评估完整导航权重。16步原停滞检测、24真实扫描、左右90度、90度恢复转向及最多8个前进动作、cooldown64、最多2次/76干预动作，全部计原500。KEEP和RETURN均为交还当前SIGN提议，不是STOP、后退、撤销真实状态或重置GRU。所有实际动作回填走原trainer钩子。

四组只在同一个RecoveryHarness中配置切换：

|组|仲裁输入与差异|
|---|---|
|A|目标、当前前向、左、右四张独立带角色图；直接left/right/keep，不使用旧默认方向否决|
|B|A选向后转向，记录第一步前进前图；执行4个实际前进动作后用同朝向前后图/真实命令问continue/return，再决定是否执行余4步|
|C|A加动作后果记忆：真实before/action/after，正常导航和恢复均稀疏写入；按候选图匹配before视角，最多2条经验|
|D|A加正常导航关键帧；按时间/新颖性保留，检索和候选图有可验证视觉对应的旧视角；无对应使用完全相同A输入|

复用SingleImageJudge的模型加载、processor、下一答案token logits读出和QwenClient常驻通信。扩展真实多图单请求与2/3词候选读出，FP32、T1，最多2个独立请求/推理batch，每请求最多8图，每图processor上限65536像素，保留完整FOV。有效输出直接argmax；候选词全词表质量不足0.1、非有限或真正并列使用KEEP/RETURN并记录。模型/运输失败安全交还SIGN并标技术异常，不能当正常完整结果；ID/SHA错配立即报错。空白/无有效视觉证据不发强制方向。

记忆使用独立CPU ORB匹配及单应RANSAC/光度核验，避免将目标条件early-fusion特征余弦当地点真值。固定参数：160像素检索图、256 ORB点、Lowe0.75、至少12匹配/10内点、内点比0.6、图像分布面积0.15、重叠0.5、归一化光度MAE不超过0.12。它只表示视觉对应，不保证同地点；正常nav无纹理等无法可靠匹配时宁可不提供记忆。

C每8实际动作考虑一个最近4动作片段，恢复的同朝向前进片段也写入；视觉变化只有无转向的前进片段可作为前进观测，其他片段不标进展或失败。容量24，更新近重复视角的同动作经验，保留实际动作、次数和结果。D容量24，正常导航最短间隔8步，图像新颖性阈值0.08、最大间隔32步，检索历史至少早于扫描触发16步。episode真实reset即清空；暂停的vector行正确移除，不跨episode写入。

C/D分别记录验证匹配数、实际进入prompt的记忆数与同输入去记忆A影子读出是否改变选择；影子只读不执行。检索命中不等于提高SR，也不当人工地点真值。C规则记忆消融使用同动作低视觉变化证据将A的选择改为KEEP；B视觉阈值消融用同朝向4步MAE0.01；D最近帧/固定私有随机检索都明确标为未验证对应，不计可靠命中。

技术检查涵盖旧单图接口、真实多图顺序/独立batch、候选交换、空图、词ID/答案位置、KEEP/RETURN、STOP中断、GRU/实际动作回填、76预算、记忆更新/清空/容量和off等价。检索质量先在已保存轨迹的历史视角上做一次固定设置检查，GT姿态只能供离线QA，绝不入记忆或prompt。测试不以旧61条成功率选择参数或反复调成正结果。
