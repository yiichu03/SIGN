这批证据最支持优先检验三种推理补充：持续受阻恢复、移动循环管理、目标确认与停止。现有Actor有GRU记忆，但没有显式访问地图或恢复状态机。原程序不提供“视觉误识别/规划失败/控制失败”的因果标签，本报告也不把自动现象变成这种真值。

覆盖代理本身需要独立检查

在可用同一保存地图审计的失败中，约90%–93%至少有一个状态投影到2D非可通行格；“至少一个”很宽松，不是90%坏轨迹。其每条轨迹非可通行投影比例中位数为19.35%/21.43%/18.76%。Habitat视线从当前格发射，起点无效就退出：Mosquito3408有498/501状态落在这种格子，原覆盖新增为0。二维栅格不等于真实navmesh，每步is_navigable未保存，不能断言真实位置不可达；也不能用零面积证明没有新视觉信息。

有非可通行投影不自动否定整条面积，短暂掠边与长期落在边界应区分；基线/覆盖256/覆盖32分别有144/135/132条失败的中间高度地图未保存，明确标记未知，不能补造。此项质量审计为采集中发现个例后的补充；原0.1m/3m/90°口径和预设行为阈值均保持。SR/SPL、目标距离和运动受阻判断不依赖这一面积代理，低增益闭环的“信息少”解释则需谨慎。

案例指向的具体机制

  • Cantwell1504持续请求约0.25m/s前进，最后64步首尾只移动0.015m，最长连续低位移前进347步：应研究停滞与有限恢复。
  • Cantwell1541在0.761m附近短暂停留后离开，反复走同一房间/走廊；需要目标确认和循环管理，而不是仅看最终面积。
  • Pablo633近目标且目标视角差不大于25°共431个状态，到500步仍在0.785m但没有STOP：位置条件已满足，停止未完成；没有证据说明模型主观识别了目标。
  • Scioto2383目标与起点高度差3.561m，XZ投影接近但测地仍5.636m：应考虑跨层连通路线，不能只靠二维图判断到达。

以上与其余案例的AI笔记均为目的性证据复核，浏览页保留图、完整视频及部分密集抽帧；17条笔记覆盖6场景，不用其比例估计全体病因。原失败ViewAngle=180°是占位值，这里的角度由真实姿态和目标四元数重算。

下一步Agent可以如何分层验证（本轮未实施）

  1. 先校准在线停滞检测：用允许的RGB变化与动作历史，若允许里程计/碰撞则明确新增输入；将有限转向/前进、有限随机扰动作为低成本恢复对照，再看VLM是否增加收益。原动作范围不含后退，物理双低速会STOP，归一化双零反而会前进；等待VLM应暂停环境step。
  2. 对重复局部循环维护访问/尝试过的出口记忆，VLM结合目标图与少量历史视图判断继续尝试还是换方向。原Actor不接受文本子目标，语言规划需要真实执行接口。共同通路、环视、受阻摆动与脱困不能直接认作无效搜索；现有top-down效率q也不是目标到达概率。
  3. 单列目标确认、最后接近和STOP复核，尤其检查正常成功轨迹被误停/误改道的代价；目标事件短，宜采用便宜的高频监控加事件触发确认，不能只在128步段末看一张图。

固定同一checkpoint/任务/目标图/500动作预算做原Actor、恢复对照、VLM各模块与组合消融，记录SR/SPL/ViewMatch、额外动作、误干预成功轨迹、调用次数与延迟。诊断GT地图/距离/位姿不应直接成为Agent输入；如使用额外传感器另列协议。先独立开发集调试并冻结方法，不能把这批已反复查看的val失败案例同时当独立测试。
